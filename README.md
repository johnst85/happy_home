# 🏡 우리 가족 하루 체크

엄마·아빠·아이들이 함께 매일 할 일을 체크하고, 점수와 가족 일정을 한 화면에서 보는 **집 안 전용 웹페이지**입니다.
집 로컬 네트워크에서만 동작하고 외부 인터넷 서비스에 의존하지 않습니다.

- 반응형 웹 + PWA (태블릿 가로 화면 기준 · 스마트폰 · 노트북)
- Node.js + Express, 데이터는 SQLite 파일 1개 (Node 내장 `node:sqlite` 사용 → Windows에서 별도 빌드 도구 불필요)
- 한 기기에서 체크하면 다른 기기에도 바로 반영 (SSE)

## 빠른 시작

필요: **Node.js 22.13 이상** (LTS 권장, https://nodejs.org)

```bash
npm install
```

```bash
npm start
```

실행되면 콘솔에 접속 주소가 나옵니다.

```
🏠 우리 가족 하루 체크 서버가 시작됐어요
   이 PC:      http://localhost:3000
   집 네트워크: http://192.168.0.10:3000
```

태블릿·폰 브라우저에서 `집 네트워크` 주소로 접속한 뒤 **"홈 화면에 추가"** 하면 앱처럼 전체 화면으로 열립니다.

- 처음 부모 PIN은 **`0000`** 입니다. 설정 › 보안·관리에서 꼭 바꿔 주세요.
- 기본 구성원(엄마·아빠·첫째·둘째), 시간대, 할 일, 보상이 미리 들어 있습니다. 설정에서 자유롭게 바꾸세요.
- 포트 변경: `PORT=8080 npm start` (Windows PowerShell: `$env:PORT=8080; npm start`)

## 화면 구성

| 메뉴 | 내용 |
| --- | --- |
| 🏠 오늘 | 구성원 얼굴을 눌러 전환 → 지금 시간대 할 일이 맨 위에. 터치하면 컨페티·효과음·칭찬 팝업·캐릭터 환호. 5초 안 되돌리기, 시간대 클리어/가족 모두 달성 특별 효과, 오늘 일정 요약, 하루 마무리, 쉬어가기권, 가족 협동 목표 |
| 🏆 점수 | 오늘/이번 주/이번 달 탭, 이전 기간 보기, 구성원별 점수·다음 보상 진행 막대·달성률, 가족 합계, 7일/4주 추이 그래프, 받은 보상 기록과 "지급 완료" |
| 📅 달력 | 월간/주간/오늘 보기, 구성원 필터, 날짜별 달성 도장(★), 일정 등록(반복·알림), 아이용 그림 아이콘 간단 등록 |
| ⚙️ 설정 | 부모 PIN 잠금. 구성원·사진·캐릭터, 할 일, 시간대, 보상, "괜찮아", 달력, 미디어 예약, 화면(다크/라이트/자동·효과음·캐릭터·글자 크기), PIN 변경·백업·복원·얼굴 데이터 삭제 |

### "괜찮아" 규칙
- 마감이 지난 할 일은 빨간 X 대신 격려 문구와 **"다시 도전"** 버튼(늦은 체크, 기본 포인트 절반)이 나옵니다. 감점은 없습니다.
- 쉬어가기권(기본 주 1장)으로 최근 7일 중 못 채운 날을 "쉬어가는 날"로 바꾸면 연속 달성이 이어집니다.
- 점수 현황은 순위 없이 각자 목표 대비 진행도로 보여 줍니다.

### 권한
- 아이: 자기 할 일 체크, 점수·달력 보기, (설정에서 허용 시) 자기 일정 간단 등록
- 부모(PIN): 설정, 아이 체크 대리·취소(5초 이후 취소는 부모만), 모든 일정 등록·수정, 보상 지급 완료 표시

## 예약 미디어 재생

1. 음원·동영상을 `media/` 폴더에 넣거나 설정 › 미디어에서 업로드합니다.
2. 예약을 추가합니다 (시각·요일·파일·재생 위치·볼륨).
   - **A. 서버 PC 스피커 (권장)**: Windows는 PowerShell 미디어 플레이어로 음원 재생(동영상은 기본 앱으로 열기), macOS는 `afplay`, Linux는 `ffplay`.
   - **B. 태블릿 화면**: 그 태블릿의 설정 › 미디어에서 "이 기기를 태블릿 재생 기기로 사용"을 켜고, 아침에 홈 화면의 **"▶ 오늘 시작하기"** 를 한 번 눌러 소리 재생 허용 + 화면 꺼짐 방지를 켭니다.
3. "▶ 테스트" 버튼으로 바로 확인할 수 있습니다.

서버의 스케줄러(node-cron)가 매분 미디어 예약, 일정 알림, 보상 기간 자동 정산을 처리하고, 매일 03:00에 DB를 `backups/`에 복사합니다(최근 30개 보관).

## Windows 서버 PC 운영

1. **고정 IP**: 공유기 관리 페이지에서 서버 PC에 DHCP 예약(고정 IP)을 걸어 둡니다.
2. **방화벽**: 처음 실행할 때 나오는 Windows 방화벽 창에서 "개인 네트워크" 허용. 또는 관리자 PowerShell:
   ```powershell
   New-NetFirewallRule -DisplayName "Happy Home" -Direction Inbound -Protocol TCP -LocalPort 3000,3443 -Action Allow -Profile Private
   ```
3. **부팅 시 자동 실행** (둘 중 하나)
   - pm2:
     ```powershell
     npm install -g pm2 pm2-windows-startup
     pm2 start server/index.js --name happy-home --node-args="--disable-warning=ExperimentalWarning"
     pm2 save
     pm2-startup install
     ```
   - 작업 스케줄러: `scripts\start-windows.bat` 을 "로그온할 때" 실행되도록 등록
4. **절전 모드 해제**: 설정 › 시스템 › 전원에서 "절전 모드: 안 함".

## HTTPS (안면인식 등 카메라 사용 시 필수)

[mkcert](https://github.com/FiloSottile/mkcert)로 집 안 전용 인증서를 만들어 `certs/` 폴더에 두면 서버가 자동으로 HTTPS(기본 3443 포트)도 엽니다.

```bash
mkcert -install
```

```bash
mkcert -cert-file certs/cert.pem -key-file certs/key.pem 192.168.0.10 localhost
```

각 태블릿·폰에는 `mkcert -CAROOT` 폴더의 `rootCA.pem` 을 설치하고 신뢰하도록 설정합니다.

점수는 별도 테이블 없이 체크 기록(`completions`)을 기간에 맞게 합산해 계산합니다.
